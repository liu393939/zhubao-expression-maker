# 助宝搞怪表情风格指南

参考图：`../assets/zhubao-expression-reference.png`

## 核心气质

不是“甜美JK写真”，而是“大学生聊天群里会疯狂转发的Q版reaction贴纸”。

关键词：古灵精怪、欠欠、抽象、戏多、反差、夸张、校园梗、表情包感。

## 表演原则

1. 表情要比动作更重要。
2. 面部可以适度变形，以读得快、好笑为准。
3. 手势要大，尤其是指人、捂脸、抱头、握拳、摊手、比耶、扒箱子边缘。
4. 小道具用于强化梗，不用于堆砌场景。
5. 允许符号化效果：汗滴、青筋、星星、问号、速度线、灵魂、阴影脸、旋涡眼。

## 常用搞怪脸

- 半眯眼 + 歪嘴：欠欠/看戏
- 白眼圆眼 + 大张嘴：震惊/CPU烧了
- 螺旋眼：晕/期末复习过载
- 豆豆眼 + 平嘴：无语/放弃思考
- 星星眼 + 鼓掌：狂喜
- 大哭瀑布泪：崩溃
- 舌头伸出 + 手指拉脸：调皮
- 小虎牙 + 坏笑：得意
- 灰脸 + 灵魂飘出：寄了

## 构图

绝大多数做上半身，放大脸和手势。

全身只用于躺平、摔倒、奔跑、爬走、打滚、冰冻、坐地等身体梗。

## 禁止方向

- 不要端庄站姿。
- 不要每张都标准微笑。
- 不要过度精致时尚大片感。
- 不要写实皮肤和真实摄影光影。
- 不要把助宝画成银发、蓝发等其他角色。
