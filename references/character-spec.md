# 助宝角色设定基准

## 身份

助宝是“文理助手”校园小程序的拟人吉祥物。整体定位是大学校园里的古灵精怪JK系Q版少女，不是正式校徽拟人，也不是现实学生写实肖像。

## 外观锚点

- Q版大头小身体，比例幼态但不是儿童写实。
- 暖深棕色头发。
- 头顶一根明显呆毛。
- 两侧低双马尾，发尾蓬松、略向外翘。
- 观看者右侧佩戴红色蝴蝶结发饰。
- 紫色大眼睛，眼内有粉紫色高光。
- 脸颊带浅红腮红。
- 可以在搞怪表情中出现小虎牙、舌头、夸张口型。

## 服装

- 深藏青色JK风西装外套。
- 白色衬衣。
- 红色领结。
- 金色/暖色小纽扣。
- 深色百褶裙，带细微红蓝格纹。
- 白袜、棕色乐福鞋（仅全身构图需要）。

## 唯一品牌标识

胸前佩戴一个小型圆形“文理助手”胸针。

胸针参考：`../assets/zhubao-badge-logo.png`

规则：

- 只作为胸针出现。
- 不作为帽徽、发卡、背景Logo、道具印刷或水印。
- 不重复出现多个Logo。
- 胸针不要抢主体。
